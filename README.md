## 🚀 Major Engineering Projects

### 01 — Lexa-ADAS | Advanced Driver Assistance System

> **Domain:** Automotive Software · Backend · Embedded Systems · Computer Vision  
> 🔗 **Repository:** [`MelihKacan/Lexa-ADAS`](https://github.com/MelihKacan/Lexa-ADAS)

Lexa-ADAS is an advanced driver assistance system developed as part of my engineering competition experience with Lexa Team. It brings together vehicle-related functions through a software system combining a Raspberry Pi, an Arduino-based hardware layer, and a web-based interface.

#### ✨ System Components & Features
* ⚙️ **Backend:** A Django and Django REST Framework application providing API functionality.
* 🔌 **Embedded integration:** Communication between Raspberry Pi and Arduino Mega.
* 📹 **Camera system:** Rear-view camera streaming.
* ⚠️ **Driver assistance:** Ultrasonic sensor-based blind-spot warnings.
* 👁️ **Computer vision:** Traffic-sign classification using a TensorFlow Lite model and visual lane-departure warnings.
* 📍 **Navigation:** GPS-based navigation and lap-tracking functionality.
* 🖥️ **Interface:** A web-based interface built with Django and jQuery.

#### 👨‍💻 My Contribution
I served as the lead software developer, working across the software components and their integration with the hardware.

This project brought together several areas I enjoy working on: backend architecture, device communication, camera systems, and software designed for a physical environment.

`Python` · `Django` · `Django REST Framework` · `SQLite` · `Raspberry Pi 5` · `Arduino Mega` · `OpenCV` · `TensorFlow Lite` · `jQuery` · `JavaScript`

### 02 — ROV | Robotics & Embedded Systems

> **Domain:** Robotics · Embedded Software · Hardware Integration  
> 🔗 **Repository:** [`MelihKacan/ROV`](https://github.com/MelihKacan/ROV)

The project has included work on a larger platform of approximately **90 × 90 × 90 cm**, built around Raspberry Pi and Arduino components, as well as a later, more compact autonomous platform of approximately **50 × 50 cm**.
